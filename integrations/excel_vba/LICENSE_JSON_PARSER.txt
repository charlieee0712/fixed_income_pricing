            original vba-json code it was based on

Why vendored rather than written in-house: this development environment has no VBA
runtime (server 47 has no Excel), so a hand-written parser would reach a live demo
never having been executed once — and the cases a parser gets wrong are exactly the
ones our responses contain, e.g. a calibration residual serialised as -5.885e-09.
